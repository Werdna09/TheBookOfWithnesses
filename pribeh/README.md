# Struktura příběhu

- `pripady/`: samostatné vyšetřovací příběhy.
- Každý případ má `PREHLED.md` a podle potřeby `DUKAZY.md`, `POSTAVY.md`, `CASOVA_OSA.md`, `LOKACE_A_ATMOSFERA.md`, `VEDLEJSI_PRIBEHY.md`.
- `kapitoly/NN_Nazev/PRIBEH.md`: co se děje, proč, co postava ví, důsledky, přechod do další kapitoly.
- `kapitoly/NN_Nazev/ATMOSFERA.md`: světlo, barvy, zvuk, prostředí, emocionální tón a vizuální motivy (bez finálních assetů).
- `kapitoly/NN_Nazev/META.yaml`: identifikátor, stav, místo, pořadí, klíčová informace, seznam souborů.

**Pozor:** kampaň obsahuje pozdní odhalení Kapituly. Souborové podklady nejsou určeny hráči; obsahují spoilery. Budoucí herní texty a viditelné dokumenty musí udržet informační hranice jednotlivých kapitol.
